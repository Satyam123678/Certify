# Certify

A quiz application.

## Overview
Certify is a quiz application that lets users take quizzes and view results. The repository contains a mix of backend logic (Java) and a web UI (HTML/TypeScript).

## Tech Stack
- **Java**
- **TypeScript**
- **HTML**

## Getting Started

### Prerequisites
- Java (JDK 8+ recommended)
- Node.js (LTS recommended)

### Run (high level)
Because project structures can vary, use the steps that match your setup:

1. **Clone the repo**
   ```bash
   git clone https://github.com/Satyam123678/Certify.git
   cd Certify
   ```

2. **Backend (Java)**
   - If you have a Maven project: `mvn spring-boot:run`
   - If you have a Gradle project: `./gradlew bootRun`

3. **Frontend (TypeScript/HTML)**
   - Install dependencies: `npm install`
   - Start dev server (if configured): `npm run dev` or `npm start`

## Project Structure
- `src/` – application source code (may include backend/frontend depending on setup)
- `public/` or `static/` – static web assets (if present)
